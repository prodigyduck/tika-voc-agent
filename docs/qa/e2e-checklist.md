비고 (2026-08-19 실행 환경·관찰):
- 실행 환경: LLM z.ai glm-4.7(OpenAI 호환 코딩 엔드포인트), DB는 sqlite(`.env`의 `DATABASE_URL`) — postgres 조건은 로컬 실행에서 sqlite로 대체
- 수동 1: "...어디서 확인하나요?"가 붙은 질문형은 사용법문의로 분류·출처 표시 확인. 끝이 짧은 진술형("완료한 할 일이 목록에서 안 보여요")은 버그제보로 분류됨 — 어느 쪽도 합리적 판단이나, 진술형 VOC의 사용법 안내 누락 가능성은 분류 프롬프트 개선 과제
- 수동 3: 기능요청 경로는 설계상 접수 안내로 응답(지어내지 않음 + 에스컬레이션 확인). "찾지 못했습니다" 문구는 사용법문의에서 청크가 없을 때의 경로
- E2E 시나리오 2("할 일을 어떻게 삭제하나요?")는 분류는 통과했으나 답변이 "메뉴얼에 없음"으로 나옴 — 어형 차이("삭제하나요" vs "삭제하기")로 검색이 매칭 못 한 것(토크나이저 어형 한계, 알려진 Minor)
