# doit 시작하기

doit에 오신 것을 환영합니다. doit은 할 일을 티켓으로 만들어 칸반 보드에서 관리하는 앱입니다.

## doit이란 무엇인가요
doit은 티켓 기반 칸반 보드 할 일 관리 앱입니다.
떠오른 할 일을 티켓으로 등록하고, 보드의 칼럼 사이로 옮기며 진행 상태를 관리합니다.
회원가입이나 로그인 없이 바로 사용할 수 있는 1인용 앱입니다.

## 기본 사용 흐름
doit은 다음 순서로 사용합니다.
1. 상단의 "새 업무" 버튼으로 티켓을 만듭니다. 새 티켓은 Backlog 칼럼 맨 위에 놓입니다.
2. 일정이 정해진 할 일은 카드를 끌어 TODO 칼럼으로 옮깁니다.
3. 작업을 시작하면 In Progress로 옮기고, 끝내면 Done으로 옮겨 완료 처리합니다.
4. Done으로 옮긴 티켓은 완료 시각부터 24시간 동안만 보드에 표시됩니다.
티켓 카드를 클릭하면 상세 정보를 확인하고 내용을 수정할 수 있습니다.

## 첫 티켓 만들기
1. 화면 오른쪽 위의 "새 업무" 버튼을 누릅니다.
2. "새 업무 생성" 창에서 제목을 입력합니다. 제목만 필수이고 설명, 우선순위, 시작예정일, 마감일은 선택입니다.
3. "생성" 버튼을 누르면 티켓이 Backlog 칼럼 맨 위에 나타납니다.

## 칸반에서 티켓 옮기기
카드를 마우스로 누른 채 원하는 칼럼으로 끌어다 놓으면 상태가 바뀝니다.
TODO로 옮기면 시작일이, Done으로 옮기면 완료일이 자동으로 기록됩니다.
같은 칼럼 안에서도 끌어다 놓아 카드 순서를 바꿀 수 있습니다.

## 첫 티켓 완료하기
할 일을 끝냈다면 카드를 끌어 Done 칼럼에 놓습니다.
Done으로 옮겨진 티켓은 완료로 처리되고 완료일이 자동으로 기록됩니다.
완료한 티켓은 완료 시각부터 24시간 동안 Done 칼럼에 표시되고, 그 후에는 보드에서 숨겨집니다.
