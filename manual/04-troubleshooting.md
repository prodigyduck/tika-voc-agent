# 문제 해결

doit에서 자주 보고되는 문제의 증상, 원인, 해결 방법을 안내합니다.

## 완료한 티켓이 보드에서 사라졌어요
**증상**: 완료(Done)으로 옮겨 완료한 티켓이 어느 순간 보드에서 보이지 않습니다.
**원인**: doit은 완료 시각부터 24시간이 지난 완료 티켓을 완료(Done) 칼럼에서 자동으로 숨깁니다. 삭제된 것이 아닙니다.
**해결**: 1. 완료한 지 24시간이 지났는지 확인해 보세요. 2. 완료한 티켓을 계속 확인하고 싶다면 캘린더 연동 설정에서 "완료된 티켓 포함"을 켜고 캘린더에서 보세요. 3. 오래된 완료 기록을 목록으로 다시 보는 기능이 필요하면 기능 요청으로 알려 주세요.
24시간이 지나기 전이라면 필터나 검색이 켜져 있는지도 함께 확인해 보세요.

## 티켓이 자꾸 원래 자리로 돌아가요
**증상**: 드래그해서 티켓을 옮겼는데 다시 제자리로 되돌아갑니다.
**원인**: 이동 결과는 서버에 저장되며 저장에 실패하면 안전하게 원래 위치로 되돌립니다. 네트워크가 불안정하거나 일시적 오류가 있을 때 나타납니다. 칼럼 내 순서는 카드를 놓은 위치 기준으로 정해지므로 비슷한 위치에 놓으면 순서가 거의 그대로일 수 있습니다.
**해결**: 1. 화면 아래에 빨간색 오류 알림이 있는지 확인하세요. 2. 페이지를 새로고침한 뒤 다시 드래그해 보세요. 3. 같은 증상이 반복되면 버그로 접수해 주세요.

## 종료일이 지났는데 표시가 이상해요
**증상**: 마감일이 지난 티켓에 경고 표시가 붙거나, 반대로 마감일이 지났는데 아무 표시가 없습니다.
**원인**: doit은 마감일이 오늘 이전 날짜이고 아직 완료(Done)가 아닌 티켓에만 일정 초과 경고를 표시합니다. 마감 당일은 아직 경고 대상이 아니고, 완료(Done)으로 옮긴 티켓은 마감일이 지나도 경고가 표시되지 않습니다.
**해결**: 1. 티켓이 완료(Done) 칼럼에 있는지, 마감일이 어제 이전인지 확인해 보세요. 2. 경고를 없애려면 티켓을 완료(Done)으로 옮기거나 마감일을 수정하세요. 3. 마감일이 지난 티켓은 "일정 초과" 필터로 한 번에 모아 확인할 수 있습니다. 4. 마감 3일 전부터는 일정 초과 경고와 별개로 마감일 임박 표시가 카드에 나타납니다.

## 새 티켓이 생성되지 않아요
**증상**: "생성" 버튼을 눌러도 티켓이 생기지 않거나 창이 닫히지 않습니다.
**원인**: 제목을 입력하지 않았거나(필수), 제목이 200자·설명이 1000자를 넘었거나, 마감일을 오늘 이전으로 선택했기 때문입니다. 시작예정일과 마감일을 모두 정할 때 마감일이 시작예정일보다 빠르면 거부됩니다. 서버 오류라면 화면 아래에 빨간색 알림이 나타납니다.
**해결**: 1. 제목을 입력했는지 확인하세요. 2. 입력 칸 아래의 오류 문구를 확인하고 해당 항목을 고쳐 주세요. 3. 마감일은 오늘 날짜부터 선택하세요. 4. 계속 실패하면 버그로 접수해 주세요.

## 검색이나 필터를 켰더니 티켓이 안 보여요
**증상**: 검색하거나 필터 버튼을 누른 뒤 카드가 사라졌습니다.
**원인**: 필터나 검색이 아직 켜져 있어 해당 조건에 맞는 티켓만 표시되고 있습니다. 삭제된 것이 아닙니다.
특히 "이번주 업무" 필터는 이번 주(월~일)에 마감일이 있는 티켓만 남기므로, 마감일이 없거나 다른 주에 마감인 티켓은 화면에서 보이지 않습니다.
**해결**: 1. 필터 바의 "초기화" 버튼을 누르거나 켜진 필터 버튼을 다시 눌러 꺼 주세요. 2. 검색창에 입력한 단어를 지워 주세요. 3. 검색은 제목과 설명에 들어 있는 단어만 찾으므로 더 짧은 단어로 검색해 보세요. 4. "이번주 업무" 필터를 켰다면 마감일이 이번 주로 되어 있는지 티켓의 마감일을 확인해 보세요.

## 삭제한 티켓을 되돌리고 싶어요
**증상**: 티켓을 삭제했는데 다시 필요해졌습니다.
**원인**: 삭제는 즉시 확정되지 않고 8초 동안 되돌릴 수 있는 시간이 주어집니다. 8초가 지나면 서버에서 영구 삭제되어 되돌릴 수 없습니다.
**해결**: 1. 삭제 직후 화면 아래 알림의 "실행취소" 버튼을 누르세요. 2. 알림이 이미 사라졌다면 티켓을 다시 만들어야 합니다. 3. 당장 없애기만 하고 나중에 다시 볼 티켓은 삭제 대신 완료(Done) 칼럼으로 옮겨 완료 처리하는 방법도 있습니다.

## 시작일·완료일이 직접 수정되지 않아요
**증상**: 상세 모달에서 시작일이나 완료일을 고치고 싶은데 입력칸이 없습니다.
**원인**: 시작일은 티켓을 할 일(TODO)로 옮긴 시각, 완료일은 완료(Done)으로 옮긴 시각을 doit이 자동으로 기록하는 정보라 사용자가 직접 편집할 수 없습니다.
**해결**: 1. 시작일을 바꾸려면 티켓을 할 일(TODO)로 다시 옮겨 보세요. 2. 완료일을 새로 남기려면 완료(Done)으로 다시 옮기면 완료 시각이 다시 기록됩니다. 3. 직접 입력이 꼭 필요하면 기능 요청으로 알려 주세요.
