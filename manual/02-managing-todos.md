# 티켓 관리

생성, 수정, 삭제, 이동, 완료 등 티켓 관리 방법을 안내합니다.

## 티켓 생성하기
1. 화면 오른쪽 위의 "새 업무" 버튼을 누릅니다.
2. "새 업무 생성" 창에서 제목(필수, 200자 이내)을 입력하고, 필요하면 설명(1000자 이내), 우선순위, 시작예정일, 마감일을 입력합니다.
3. "생성" 버튼을 누르면 티켓이 Backlog 칼럼 맨 위에 추가됩니다.
마감일은 오늘 이후 날짜만 선택할 수 있습니다.

## 티켓 내용 수정하기
수정할 티켓 카드를 클릭하면 상세 모달이 열립니다.
"편집" 영역에서 제목, 설명, 우선순위, 시작예정일, 마감일을 고치고 "저장" 버튼을 누릅니다.
수정한 내용은 보드의 카드에 바로 반영됩니다.

## 티켓 삭제하기
삭제는 두 가지 방법으로 할 수 있습니다.
- 상세 모달 오른쪽 위의 "삭제" 버튼을 누르고 확인 창에서 "확인"을 누릅니다.
- 카드를 끌어 드래그 중에 나타나는 삭제(휴지통) 영역에 놓습니다.
삭제하면 화면 아래에 "실행취소" 알림이 8초 동안 나타납니다.
이때 "실행취소"를 누르면 티켓이 제자리로 돌아오고, 8초가 지나면 영구 삭제됩니다.

## 티켓 이동하기 (드래그앤드롭)
카드를 끌어 원하는 칼럼에 놓으면 상태가 바뀝니다.
Backlog에서 TODO, In Progress, Done 순서로 진행하고 반대 방향으로 되돌릴 수도 있습니다.
같은 칼럼 안에서 카드를 끌어 순서를 바꿀 수 있고, 놓은 위치가 그대로 저장됩니다.
이동 결과는 서버에 저장되며 저장에 실패하면 카드는 안전하게 원래 자리로 되돌아갑니다.

## 티켓 완료하기
카드를 Done 칼럼으로 옮기면 완료로 처리되고 완료일이 자동으로 기록됩니다.
Done에 있는 카드를 다른 칼럼으로 꺼내면 완료가 해제되고 완료일이 초기화됩니다.
완료한 티켓은 완료 시각부터 24시간 동안만 Done 칼럼에 표시되고 그 후에는 보드에서 숨겨집니다.

## 우선순위 정하기
생성·수정 화면에서 우선순위를 낮음, 보통, 높음 중에서 고릅니다. 선택하지 않으면 보통이 적용됩니다.
우선순위는 카드의 뱃지로 표시되며 높음은 빨간색, 보통은 파란색, 낮음은 회색입니다.
고급 필터에서 우선순위를 골라 해당 티켓만 모아 볼 수 있습니다.

## 시작예정일·마감일 설정하기
생성·수정 화면에서 시작예정일과 마감일을 날짜로 선택합니다.
마감일은 오늘 이후 날짜만 선택할 수 있고, 마감 3일 전부터 카드에 임박 표시가 나타납니다.
마감일이 지났는데 완료(Done)하지 않은 티켓에는 일정 초과 경고가 표시됩니다.
상세 모달의 시작일·완료일은 TODO·Done으로 옮긴 시각을 doit이 자동 기록한 값이라 직접 고칠 수 없습니다.

## 티켓 검색하기
화면 오른쪽 위의 검색창에 단어를 입력하면 제목과 설명에서 해당 단어를 찾아 보드를 걸러 줍니다.
고급 필터의 검색창에서도 같은 방법으로 검색할 수 있고 대소문자는 구분하지 않습니다.

## 이번주 업무·일정 초과 필터 사용하기
보드 위 필터 바의 "이번주 업무" 버튼을 누르면 이번 주(월~일)에 마감일이 있는 TODO·In Progress 티켓만 남습니다.
"일정 초과" 버튼을 누르면 마감일이 지났는데 완료하지 않은 티켓만 남습니다.
버튼 오른쪽 숫자는 해당 티켓 수입니다. 필터 버튼을 다시 누르거나 "초기화" 버튼으로 끌 수 있습니다.
필터 결과가 없으면 "선택한 필터에 해당하는 업무가 없습니다" 안내와 "필터 초기화" 버튼이 나타납니다.
