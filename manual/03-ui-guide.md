# 화면 구성 가이드

doit 화면의 구성 요소와 조작 방법을 안내합니다.

## 기본 화면 구성
화면은 크게 세 부분으로 구성됩니다.
- 상단 영역: doit 타이틀, 다크 모드 전환 버튼, 캘린더 연동 설정 버튼, "새 업무" 버튼, 검색창
- 필터 바: "이번주 업무", "일정 초과" 필터 버튼과 고급 필터
- 칸반 보드: Backlog, TODO, In Progress, Done 네 개 칼럼

## 네 개 칼럼 (Backlog·TODO·In Progress·Done)
칸반 보드의 칼럼은 Backlog, TODO, In Progress, Done 네 개로 고정되어 있습니다.
- Backlog: 아직 일정이 정해지지 않은 할 일이 쌓이는 곳. 새 티켓은 여기 맨 위에 추가됩니다.
- TODO: 오늘 또는 이번 주에 처리하기로 한 할 일
- In Progress: 지금 진행 중인 작업
- Done: 완료된 작업. 완료 시각부터 24시간 동안만 표시됩니다.
각 칼럼 이름 오른쪽에는 칼럼에 있는 카드 수가 표시됩니다.

## 티켓 카드
카드에는 제목, 설명, 우선순위 뱃지(낮음·보통·높음), 마감일이 표시됩니다.
마감 3일 전부터는 마감일이 임박 색으로 표시되고, 마감일이 지난 미완료 티켓에는 일정 초과 경고가 표시됩니다.
카드를 클릭하면 상세 모달이 열리고, 끌어다 놓아 칼럼을 옮길 수 있습니다.

## 상세 모달
카드를 클릭하면 상세 모달이 열립니다.
"메타 정보" 영역에서 상태, 시작일, 완료일, 생성일을 확인할 수 있습니다.
"편집" 영역에서 제목, 설명, 우선순위, 시작예정일, 마감일을 고칠 수 있습니다.
오른쪽 위 "삭제" 버튼으로 티켓을 삭제할 수 있습니다.

## 검색과 필터 바
상단 검색창 또는 고급 필터의 검색창에 단어를 입력하면 제목과 설명에서 찾아 줍니다.
고급 필터에서는 우선순위(높음·보통·낮음)와 상태(칼럼)를 골라 볼 수 있고 "초기화" 버튼으로 모두 해제합니다.
검색이나 필터 결과가 없으면 안내 문구와 "필터 초기화" 버튼이 나타납니다.

## 캘린더 연동 설정 화면
상단의 ⚙ 버튼을 누르면 "캘린더 연동" 설정 창이 열립니다.
피드 URL을 복사해 구글 캘린더 "URL로 추가"에 등록하면 티켓 일정을 캘린더에서 볼 수 있습니다.
"백로그 포함", "완료된 티켓 포함" 스위치로 캘린더에 표시할 범위를 정하고 "저장"을 누릅니다.

## 알림 메시지 (토스트)
저장, 삭제, 오류 등 작업 결과는 화면 아래에 잠깐 나타나는 알림으로 확인할 수 있습니다.
티켓을 삭제하면 "실행취소" 버튼이 있는 알림이 8초 동안 표시됩니다.
문제가 생겼을 때는 빨간색 알림으로 원인이 표시됩니다.

## 모바일 화면
모바일에서는 칼럼이 세로로 이어져 표시되고 터치로 카드를 끌 수 있습니다.
카드 오른쪽의 ⋯ 버튼을 누르면 상세 보기, 칼럼 이동, 삭제를 고를 수 있습니다.
